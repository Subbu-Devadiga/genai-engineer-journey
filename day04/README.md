\## Key learning



Activation functions introduce non-linearity, allowing

neural networks to learn complex relationships.



\## Important observation



An inappropriate learning rate can cause training

to become unstable or prevent the model from converging.



\## Interview takeaway



Using only linear functions in every layer would make

the entire network effectively behave like a linear

transformation, limiting its ability to learn nonlinear

relationships.
